# Code of Conduct

## Our Pledge

We pledge to make participation in this project a respectful and harassment-free experience for everyone, regardless of background or experience level.

## Our Standards

- Be respectful and kind to others.
- Welcome different viewpoints and experiences.
- Accept constructive feedback gracefully.
- Do not use offensive language or harass anyone.

## Enforcement Responsibilities

The project owner is responsible for clarifying the standards of acceptable behavior and will take fair and appropriate action in response to any behavior that is unacceptable.

## Scope

This Code of Conduct applies to all project spaces, including issues, pull requests, discussions and any other place where the project is represented.

## Enforcement

Instances of unacceptable behavior may be reported to the project owner. All reports will be reviewed and handled fairly. The project owner may remove, edit or reject contributions that do not follow this Code of Conduct.

## Enforcement Guidelines

1. **Correction:** A private, written warning explaining the problem and why the behavior was inappropriate.
2. **Warning:** A warning with consequences for continued behavior, such as limited interaction for a set period.
3. **Temporary Ban:** A temporary ban from any interaction with the project.
4. **Permanent Ban:** A permanent ban from the project for repeated or serious violations.
