## Simple Interest Calculator

This project includes `simple-interest.sh`, a Bash script that calculates simple interest from user input.

It asks for:

- Principal amount (p)
- Rate of interest (r)
- Time period in years (t)

Formula: simple interest = (p * r * t) / 100
